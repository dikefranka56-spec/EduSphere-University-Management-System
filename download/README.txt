EduSphere - University Management System
1) Install XAMPP from apachefriends.org. 2) Extract to C:\xampp\htdocs\EduSphere. 3) Start Apache+MySQL. 4) phpMyAdmin > create edusphere > Import database.sql. 5) Edit config.php DB credentials (default root / empty). 6) Open http://localhost/EduSphere/setup_admin.php create admin (min 10 chars) then DELETE setup_admin.php. 7) Login at http://localhost/EduSphere/login.php. 8) Test: Admin creates faculties/departments/courses, approves enrolments, issues invoices; Student registers via register.php, registers courses, views results/fees; Lecturer (created by admin) records attendance, assessments, results. 9) Troubleshoot: DB failed = check MySQL running/import/config; blank page = check PHP 8+ and Apache logs. 10) InfinityFree: create DB, upload files to htdocs, import database.sql via phpMyAdmin, edit config.php with hosting credentials, run setup_admin.php once then DELETE it.
Security: password_hash, PDO prepared statements, CSRF, role checks, escaped output. Manual payments are NOT verified gateway payments.
