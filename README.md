# EduSphere – University Management System

A full-stack University Management System designed to simplify academic administration and improve the management of student information, course enrolments, academic records, and university operations.

**Live Demo:** https://edusphereuniversity.my-board.org

---

## Project Overview

EduSphere is a web-based university management platform developed to provide separate portals for students and administrators.

The system brings important academic and administrative activities into one centralized application. Students can access their academic information and manage course-related activities, while administrators can manage institutional records and oversee university operations.

The project demonstrates practical full-stack web development using PHP, MySQL, JavaScript, HTML5, and CSS3.

## Key Features

### Student Portal
- Student account registration and authentication.
- Student dashboard.
- Course registration and enrolment.
- Academic information and records.
- Results and performance information.
- Access to university announcements and relevant updates.

### Admin Portal
- Dedicated administrator authentication.
- Administrative dashboard.
- Student record management.
- Academic session and semester management.
- Course and enrolment management.
- Results and academic administration.
- Fee and payment record management.
- University announcements and notifications.

### General Features
- Role-based access for different users.
- Database-driven application.
- Structured academic management.
- Responsive web interface.
- Secure password hashing and session-based authentication.

## System Architecture

EduSphere follows a server-side web application architecture:

- **Frontend:** HTML5, CSS3, and JavaScript.
- **Backend:** PHP.
- **Database:** MySQL.
- **Web Server:** Apache.

The application processes user requests through PHP and stores and retrieves application data using MySQL.

## Installation and Setup

To run EduSphere locally:

1. Install XAMPP on your computer.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Download or clone this repository.
4. Move the project folder into the XAMPP `htdocs` directory.
5. Create a MySQL database using phpMyAdmin.
6. Import the project's database SQL file.
7. Configure the database connection using your local database credentials.
8. Open the project in your browser:

```text
http://localhost/EduSphere-University-Management-System/
```

**Note:** Database configuration may need to be adjusted to match your local environment.

## Security Considerations

The application uses authentication, password hashing, session-based access, and role-based permissions.

For production deployment, database credentials and other sensitive configuration details should be stored securely and excluded from public source control.
